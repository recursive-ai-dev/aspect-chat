We are developing a single page html that takes inference from user-set api endpoint, model, and key, where the AI model talks through a user created Aspect. The Aspect creation involves setting a name for the Aspect, a user-facing description, instructions that the api model is given like a system prompt before each time they respond to the user, custom javascript injectable tools the user can upload that the model can execute/run, and a small knowledge bank that the AI model can reference for more information about it's purpose as the Aspect. The aesthetic of the app is a cartoony, american art, atmospheric style that gives a sense of serenity. Each aspect's icon can be edited by user uploading a 512x512 image to represent the Aspect. The list of created aspects will be off to the left in a vertical panel with the name of the aspect. Below the last Aspect in the user's created list is a + button to create another. Each Aspect is downloadable and uploadable as a .aspect file, which the app parses to fill out what the user can fill out by hand if they choose. The .aspect file is just a compressed folder that is structured as /Name.md /Description.md /Instructions.md /Tools/ToolName.js /Knowledge/KnowledgeFile.md. /ChatHistory/History.md. This is how the user keeps persistence across sessions. A panel always appears upon load with a multipage explanation of the Aspect system the user can press Ok to ignore, and a clear and apparent Save button exists so the user is reminded to save the Aspect. The chat window will have the api model's responses appear on the left-middle of the chat window, where the user's will appear on the right-middle of the chat window. There will be a text input and a send button for the user, and any uploaded .js file tool will appear by name in a tools dropdown that expands upwards instead of down.
