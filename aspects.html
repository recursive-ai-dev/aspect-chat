Welcome to Aspect Studio! 🌸

Aspects are custom AI personas. You can define their name, personality, knowledge bank, and even load custom JavaScript tools they can run autonomously during chat!

How to Set Up ⚙️

1. API Settings: Click the Gear icon in the sidebar to enter your model's endpoint, model name, and API Key.
2. Create Aspect: Click "+ New Aspect" to start sketching out a persona.
3. Customize: Add custom instructions (system prompt), knowledge articles, and custom script tools.

Persistence & Saving 💾

This is a local browser app. All changes are saved temporarily in your local storage, but to keep your Aspects permanent, click the Download button to export your setup as a .aspect file! You can upload it later using "Upload .aspect".
